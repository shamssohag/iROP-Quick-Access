1. Introduction & Core Purpose
iROP Quick Access is a lightweight, responsive desktop launcher built to eliminate the everyday frustration of repeatedly clicking through "This PC", navigating deep nested subdirectories, and searching for frequently used work locations.
Drag and drop any folder, drive, application (.exe), or file directly into the app window to turn it into an instant visual shortcut card.
Cards automatically arrange themselves by usage frequency and recency, keeping your most active projects always within a single click.
It is a multi-purpose workspace shortcut hub that supports:
  • Local Folders & Subfolders: e.g., C:\Projects\ClientWork, D:\Photos.
  • Hard Disk Drives & Network Shares: e.g., C:\, D:\, T:\Multimedia, network NAS drives.
  • Software & Executables: e.g., .exe applications and desktop shortcuts (.lnk).
  • Project Files & Documents: e.g., .psd, .ai, .prproj, .xlsx, .docx, .pdf, etc.
  • Websites & Web Links (URLs): e.g., https://github.com, www.google.com, https://youtube.com, cloud dashboards, web apps, and frequently visited online portals.
You have six flexible and lightning-fast methods:
  1. Universal Keyboard Shortcuts (Fastest): Press Ctrl+Shift+F to browse for a Folder/Drive, Ctrl+Shift+A (or Ctrl+O) for Application/File, Ctrl+Shift+W for Web Link, or Ctrl+Shift+G to Make a New Group.
  2. Canvas Right-Click Context Menu: Right-click anywhere on the empty grid background to immediately open the Add Folder, Add App/File, Add Web Link, or Make New Group context menu.
  3. Drag & Drop: Drag any folder, drive partition, software (.exe/.lnk), document, or web link/URL directly from any browser (Chrome, Edge, Firefox) into the app window.
  4. Top Bar Menu: Click the ➕ Add Folder/App button on the top toolbar and select from the dropdown with visible keyboard shortcut hints.
  5. Add Web Link Dialog: Open 🌐 Add Website / Web Link..., paste any URL (e.g. github.com or https://google.com), and optionally enter a custom title.
  6. Batch Import: Click 📥 Import Quick Access or 📂 Import Open Windows to import multiple locations simultaneously.
Native Web Link & Browser URL Integration:
  • Via Top Toolbar: Click ➕ Add Folder/App → 🌐 Add Website / Web Link.... Enter the website address (e.g. https://github.com or www.google.com). If you type a domain without a protocol, https:// is automatically prepended.
  • Smart Auto-Naming: You can provide a custom name (e.g., "Company Portal"). If left blank, the app intelligently extracts and capitalizes the website domain name (e.g., "Github", "Google").
  • Browser Drag & Drop: Simply drag any URL or bookmark directly from Google Chrome, Microsoft Edge, or Mozilla Firefox into the app window.
  • 1-Click Instant Launch: Clicking a web card immediately opens the website in your default Windows browser.
  • Desktop Internet Shortcut: Right-click any web card → 🖥️ Create Desktop Shortcut to instantly create a standard Windows .url Internet Shortcut on your Desktop.
Smart Window Focus: When you open a folder shortcut that is already open or minimized on your taskbar, iROP Quick Access intelligently detects the existing Explorer window, restores it from its minimized state, and brings it straight to the foreground. This eliminates cluttered duplicate windows. If the folder is not currently open, it launches a fresh Explorer window.

3. Card Anatomy & Advanced Actions
Every card has a dedicated 📌 pin button on its top-right corner.
  • Clicking 📌 locks the card with a soft accent border and highlights the pin button.
  • Pinned items are strictly locked to the top of the grid and list. They will never get pushed down by newly added or frequently clicked unpinned items.
  • Clicking the pin button again unpins the card and returns it to normal recency-based sorting.
Click the ✕ button located at the top-right corner of any card (it highlights in Windows close-red on hover). The shortcut is instantly removed from your view and saved.

Note: Removing a shortcut only deletes the bookmark in iROP Quick Access; your actual files, folders, and drives are never touched or modified.
Right-clicking on any card reveals a convenient context menu:
  • Open / Launch: Opens the folder or executes the file.
  • Pin to Top / Unpin: Locks or unlocks the shortcut to the top.
  • Rename: Assigns a friendly custom display name to the card without altering the actual filesystem directory name.
  • Enable Position Change (Drag & Move): Activates Rearrange Mode so you can freely drag cards with the mouse and drop them into new positions to set manual priority. When active, clicking will never accidentally launch folders, even with Single Click mode turned on!
  • Assign Shortcut Key: Assigns a fast keyboard hotkey (e.g. Ctrl+1, Ctrl+Alt+F, F2) to launch this item anytime. Warns automatically if the key is already in use by another card.
  • Create Desktop Shortcut: Generates a standard Windows desktop shortcut (.lnk) on your Desktop.
  • Copy Path: Copies the full filesystem path to your Windows clipboard.
  • Remove Shortcut: Prompts for confirmation before safely removing the shortcut card.

  • স্বয়ংক্রিয় URL ফরম্যাটিং: ডায়লগ বক্সে যেকোনো ওয়েবসাইটের ঠিকানা (যেমন: https://github.com বা শুধু www.google.com) দিন। আপনি https:// না লিখলেও অ্যাপ স্বয়ংক্রিয়ভাবে তা যুক্ত করে নিবে।
  • স্মার্ট নাম নির্ধারণ: আপনি চাইলে কার্ডের জন্য কাস্টম নাম দিতে পারেন (যেমন: "Office Dashboard")। নাম ফাঁকা রাখলে স্বয়ংক্রিয়ভাবে ওয়েবসাইটের ডোমেইন নেম (যেমন: "Github", "Google") কার্ডের টাইটেল হিসেবে বসে যাবে।
  • ব্রাউজার থেকে সরাসরি ড্র্যাগ অ্যান্ড ড্রপ: গুগল ক্রোম, এজ বা ফায়ারফক্স ব্রাউজারের অ্যাড্রেস বার থেকে যেকোনো লিংক সরাসরি অ্যাপে ড্র্যাগ অ্যান্ড ড্রপ করলেই সাথে সাথে ওয়েব কার্ড তৈরি হয়ে যাবে।
  • ১-ক্লিকে ওপেন: কার্ডটিতে ক্লিক করলেই উইন্ডোজের ডিফল্ট ব্রাউজারে ওয়েবসাইটটি মুহূর্তের মধ্যে ওপেন হবে।
  • ডেস্কটপ ইন্টারনেট শর্টকাট: ওয়েব কার্ডে রাইট-ক্লিক করে 🖥️ Create Desktop Shortcut চাপলে উইন্ডোজ ডেস্কটপে সরাসরি নেটিভ .url ইন্টারনেট শর্টকাট তৈরি হবে।
স্মার্ট উইন্ডো ফোকাস: যদি কোনো ফোল্ডার ইতিমধ্যে টাস্কবারে ওপেন বা মিনিমাইজ করা থাকে, তবে iROP Quick Access নতুন করে কোনো ডুপ্লিকেট উইন্ডো খুলবে না। বরং বিদ্যমান মিনিমাইজড উইন্ডোটিকে সাথে সাথে স্ক্রিনের সামনে (Foreground Focus) নিয়ে আসবে। আর যদি খোলা না থাকে, তবে নতুন এক্সপ্লোরার উইন্ডোতে চালু করবে।
২. কন্ট্রোলবার ও সেটিংস গাইড
📥 Import Quick Access বাটনে ক্লিক করলে এটি উইন্ডোজের আসল কুইক এক্সেস শেল নেমস্পেস চেক করে। আপনার পিসির বিভিন্ন ড্রাইভে (C:, D:, E:, T:) পিন করা সমস্ত ফোল্ডার স্বয়ংক্রিয়ভাবে ডিটেক্ট করে এবং সেগুলোকে সরাসরি টপে পিন করে ইমপোর্ট করে।
কাজের সময় আপনার টাস্কবারে বর্তমানে যেসব ফোল্ডার খোলা আছে, 📂 Import Open Windows বাটনে এক ক্লিক করলেই সবগুলো খোলা উইন্ডোর পাথ একসাথে শর্টকাট হিসেবে যুক্ত হয়ে যাবে।
টপবারের ক্লিক ড্রপডাউন থেকে আপনার পছন্দমতো মোড নির্বাচন করতে পারেন:
  • Single Click to Open: মাউসের এক ক্লিকেই ফোল্ডার বা সফটওয়্যার ওপেন হবে (দ্রুত কাজের জন্য আদর্শ)।
  • Double Click to Open: উইন্ডোজের স্ট্যান্ডার্ড নিয়মে ডাবল ক্লিকে ওপেন হবে, যাতে ভুলবশত ক্লিক হওয়া এড়ানো যায়।
টপবারের Size: স্লাইডার টেনে কার্ডের প্রস্থ ১৫০px থেকে ৩৫৫px পর্যন্ত ছোট-বড় করা যায়।
  • প্রোপোরশনাল আইকন স্কেলিং: কার্ড বড় বা ছোট করার সাথে সাথে ভেতরের আইকনটিও অনুপাত অনুযায়ী ২৪px থেকে ৪৮px পর্যন্ত বড়-ছোট হয়।
  • ↺ Default বাটন: এই বাটনে চাপলে কার্ডের সাইজ মুহূর্তেই স্ট্যান্ডার্ড ডিফল্ট ২০৫x১০৫ সাইজে রিসেট হয়ে যায়।
থিম বাটন এবং অ্যাবাউট বাটনের মাঝে থাকা 💾 Save ড্রপডাউন (ও ইউনিভার্সাল কিবোর্ড কমান্ড) থেকে:
  • Save Current as Named Preset... (Ctrl+S): পছন্দমতো নাম দিয়ে (যেমন: Work, Video Editing, Daily) সম্পূর্ণ ওয়ার্কস্পেস ও গ্রুপের পূর্ণাঙ্গ প্রিসেট সেভ করা যায়।
  • Export Shortcuts Backup... (Ctrl+E): সমস্ত শর্টকাট, গ্রুপ তালিকা, পিন ও ক্লিক হিস্ট্রি একটি পোর্টেবল JSON ফাইলে ব্যাকআপ সেভ করে রাখা যায়।
  • Import Shortcuts Backup... (Ctrl+I): যেকোনো পূর্ববর্তী ব্যাকআপ ফাইল থেকে মুহূর্তেই সমস্ত শর্টকাট ও গ্রুপ ফিরিয়ে আনা যায়।
  • Recent Presets (Last 10): সেভ করা বা ইমপোর্ট করা সর্বশেষ ১০টি প্রিসেট ফাইলে ১-ক্লিকেই সুইচ করা যায়।
  • Clear All Shortcuts...: কনফার্মেশন নিয়ে এক ক্লিকেই সমস্ত শর্টকাট ক্লিয়ার করা যায়।
টপ কন্ট্রোল বারে ডার্ক/লাইট মোড বাটনের ঠিক আগে থাকা 🎨 BG বাটন থেকে আপনি অ্যাপের ব্যাকগ্রাউন্ড কালার পরিবর্তন করতে পারবেন:
  • কালার প্রিসেট: ডার্ক এবং লাইট উভয় মোডের সাথে মানানসই চমৎকার হালকা প্রিসেট রয়েছে (যেমন: 🔹 Slate Navy, 🌿 Forest Mint, 💜 Soft Lavender, ☕ Warm Sand, 🌊 Ocean Cyan, 🌑 Deep Carbon / Pure White)।
  • 🎨 Pick Custom Color...: এই অপশন দিয়ে কালার পিকার প্যালেট থেকে যেকোনো পছন্দের কালার নির্বাচন করা যায়।
  • ↺ Reset to Default: যেকোনো সময় ডিফল্ট থিম ব্যাকগ্রাউন্ডে ফিরে আসা যায়।
💾 Save মেনুর নিচে:
  • Save Current as Named Preset...: বর্তমান শর্টকাট সেট, গ্রুপ তালিকা ও গ্রুপের কালারসমূহ একটি নির্দিষ্ট নামে আলাদা প্রিসেট হিসেবে সেভ করতে পারবেন। পূর্বের নামের সাথে মিল থাকলে ভুলবশত মোছা রোধে একটি স্পষ্ট ওভাররাইট সতর্কতা ডায়লগ (Overwrite Warning) কনফার্মেশন চাইবে।
  • সর্বশেষ ১০টি প্রিসেট তালিকা: আপনার তৈরি করা বা ইমপোর্ট করা সর্বশেষ ১০টি প্রিসেট স্বয়ংক্রিয়ভাবে ── Recent Presets (Last 10) ── সেকশনে ক্রমানুসারে সেভ থাকে।
  • ১-ক্লিকে লোড: তালিকায় থাকা যেকোনো প্রিসেটে ক্লিক করলেই সাথে সাথে সেই সম্পূর্ণ শর্টকাটগুলো অ্যাপে লোড হয়ে যায়।
৩. কার্ডের খুঁটিনাটি ও কনটেক্সট মেনু
প্রতিটি কার্ডের ওপরের ডান কোণায় একটি করে 📌 পিন বাটন রয়েছে।
  • লক টু টপ: পিন বাটনে ক্লিক করলে কার্ডটির বর্ডার ও পিন হাইলাইট হয়ে যায় এবং কার্ডটি গ্রিড বা লিস্টের সবার উপরে স্থায়ীভাবে লক হয়ে থাকে।
  • অন্যান্য ফোল্ডার যতবারই ওপেন করা হোক না কেন, পিন করা ফোল্ডার কখনোই নিচে নামবে না।
  • পুনরায় পিন বাটনে ক্লিক করলে আনপিন হয়ে স্বাভাবিক সর্টিং অর্ডারে ফিরে যাবে।
যেকোনো কার্ডের ওপরের ডান কোণায় থাকা ✕ বাটনে ক্লিক করলেই শর্টকাটটি তালিকা থেকে মুছে যাবে।

মনে রাখবেন: এটি শুধুমাত্র শর্টকাট বুকমার্কটি ডিলিট করে, আপনার আসল ফোল্ডার বা ফাইলের কোনো ক্ষতি হয় না।
যেকোনো কার্ডের ওপর মাউসের রাইট-ক্লিক করলে বিশেষ মেনু পাওয়া যায়:
  • Open / Launch: সরাসরি ফোল্ডার বা ফাইল ওপেন করে।
  • Pin to Top / Unpin: সবার ওপরে লক বা আনলক করে।
  • Rename: ড্রাইভের মূল ফোল্ডার নেম অপরিবর্তিত রেখে কার্ডে নিজের ইচ্ছামতো সুন্দর নাম দেওয়া যায়।
  • Enable Position Change (Drag & Move): মাউস দিয়ে ড্র্যাগ করে কার্ডের স্থান ও প্রায়োরিটি পরিবর্তনের মোড চালু করে। এটি চালু থাকলে সিঙ্গেল ক্লিক মোড সক্রিয় থাকলেও ভুলবশত কোনো ফোল্ডার ওপেন হবে না, নির্ভয়ে মাউস দিয়ে টেনে যেকোনো কার্ড নতুন জায়গায় বসানো যাবে। কাজ শেষে পুনরায় রাইট-ক্লিক করে মোডটি বন্ধ করা যায়।
  • Assign Shortcut Key: কার্ডটিতে কিবোর্ড শর্টকাট কি (যেমন: Ctrl+1, F2) অ্যাসাইন করা যায়। একই কি একাধিক কার্ডে অ্যাসাইন করতে গেলে স্বয়ংক্রিয় ওয়ার্নিং অ্যালার্ট আসবে।
  • Create Desktop Shortcut: সরাসরি ব্যবহারকারীর উইন্ডোজ ডেস্কটপে এই ফোল্ডারের একটি (.lnk) শর্টকাট তৈরি করে দেয়।
  • Copy Path: সম্পূর্ণ পাথ এক ক্লিকে ক্লিপবোর্ডে কপি করে।
  • Remove Shortcut: ভুলবশত ডিলিট হওয়া এড়াতে কনফার্মেশন প্রম্পট দেখিয়ে নিরাপদে শর্টকাট মুছে দেয়।
টপ মেনু থেকে সহজেই ভিউ পরিবর্তন করা যায়:
  • Grid View (205x105): চারকোনা মাল্টি-কলাম কার্ড, যাতে আইকন, টাইটেল, হালকা গ্রে পাথ এবং ব্যবহারের হিসাব সুন্দরভাবে সাজানো থাকে। বড় স্ক্রিনের জন্য উপযুক্ত।
  • List View (Auto 100% Wide): ফুল-উইডথ এক সারির তালিকা, যাতে বামে বড় ৪০px আইকন এবং পাশে টাইটেল, পাথ ও ব্যবহারের সময় পরপর সাজানো থাকে।
যেকোনো কার্ডের ওপর মাউসের রাইট-ক্লিক করলে নতুন পাওয়ারফুল অপশন পাওয়া যায়:
  • ⌨️ Assign Shortcut Key...: কার্ডটিতে যেকোনো কিবোর্ড হটকি (যেমন: Ctrl+1, Alt+1, F2) যুক্ত করা যায়। অ্যাপ চালু থাকা অবস্থায় কিবোর্ডে উক্ত কি চাপলেই সাথে সাথে সেই ফোল্ডার বা ওয়েবসাইট ওপেন হয়ে যাবে। কার্ডের নিচে [Ctrl+1] ব্যাজ প্রদর্শিত হয়।
  • কঠোর ওভাররাইট সুরক্ষা ও সাজেশন: ইউনিভার্সাল সিস্টেম শর্টকাট (Ctrl+S, Ctrl+E, Ctrl+I, Ctrl+Shift+F ইত্যাদি) অথবা অন্য কোনো কার্ডের শর্টকাটের সাথে মিলে গেলে এটি কখনোই ওভাররাইট হতে দেবে না। ডায়লগে লাল ওয়ার্নিং আসবে এবং ১-ক্লিকেই পরবর্তী উন্মুক্ত নিরাপদ হটকি বেছে নেওয়ার জন্য 💡 Suggest: [Ctrl+1] বাটন থাকবে।
  • 🖥️ Create Desktop Shortcut: এক ক্লিকেই ফোল্ডার বা অ্যাপের জন্য ডেস্কটপে .lnk ফাইল এবং ওয়েবসাইটের জন্য .url ইন্টারনেট শর্টকাট ফাইল তৈরি করে দেয়।
