v1.1 Windows Workspace & Shortcut Launcher

iROP Quick Access V.1.1

A quick solution for recent shortcut — Complete User Manual & FAQ

1. Introduction & Core Purpose
iROP Quick Access is a lightweight, responsive desktop launcher built to eliminate the everyday frustration of repeatedly clicking through "This PC", navigating deep nested subdirectories, and searching for frequently used work locations.
Drag and drop any folder, drive, application (.exe), or file directly into the app window to turn it into an instant visual shortcut card.
Cards automatically arrange themselves by usage frequency and recency, keeping your most active projects always within a single click.
It is a multi-purpose workspace shortcut hub that supports:
  • Local Folders & Subfolders: e.g., C:\Projects\ClientWork, D:\Photos.
  • Hard Disk Drives & Network Shares: e.g., C:\, D:\, T:\Multimedia, network NAS drives.
  • Software & Executables: e.g., .exe applications and desktop shortcuts (.lnk).
  • Project Files & Documents: e.g., .psd, .ai, .prproj, .xlsx, .docx, .pdf, etc.
You have three easy methods:
  1. Drag & Drop (Fastest): Drag any folder, drive, software, or document from Windows Explorer or your Desktop and drop it anywhere into the app window.
  2. Top Bar Menu: Click the ➕ Add Folder/App button on the top toolbar and select either 📁 Add Folder or Drive... or ⚡ Add Application or File....
  3. Batch Import: Click 📥 Import Quick Access or 📂 Import Open Windows to import multiple locations simultaneously.
Smart Window Focus: When you open a folder shortcut that is already open or minimized on your taskbar, iROP Quick Access intelligently detects the existing Explorer window, restores it from its minimized state, and brings it straight to the foreground. This eliminates cluttered duplicate windows. If the folder is not currently open, it launches a fresh Explorer window.
2. Top Control Bar Features
Clicking 📥 Import Quick Access queries the genuine Windows Quick Access shell namespace. It automatically scans all drives (C:, D:, E:, T:, etc.) and brings in all folders and partitions that you have pinned in your Windows File Explorer, marking them as pinned in iROP Quick Access.
Clicking 📂 Import Open Windows inspects all currently active File Explorer windows on your Windows taskbar. It instantly grabs their exact filesystem paths and registers them as shortcut cards, making it easy to capture your active multitasking session in one click.
On the top control bar, select from the click mode dropdown:
  • Single Click to Open: Opens or focuses the target folder/app immediately on a single mouse click (hyper-fast workflow).
  • Double Click to Open: Mimics classic Windows desktop behavior, opening on double-click to prevent accidental launches.
Your preference is automatically saved and remembered.
The Size: slider allows scaling card width anywhere from 150px up to 355px.
  • Adaptive Scaling: As you increase or decrease card size, the inner folder/app icons dynamically resize in proportion (from 24px up to 48px).
  • ↺ Default Button: Clicking this button immediately resets the card size to the default standard 205W x 105H.
Located between the Theme button and About button, the 💾 Save dropdown menu provides:
  • Export Shortcuts...: Saves your complete list of shortcuts, custom names, pin statuses, and click history into a portable backup file.
  • Import Shortcuts...: Restores or merges shortcuts from any previously saved backup file.
  • Clear All Shortcuts...: Safely clears all shortcut cards after prompting for confirmation.
3. Card Anatomy & Advanced Actions
Every card has a dedicated 📌 pin button on its top-right corner.
  • Clicking 📌 locks the card with a soft accent border and highlights the pin button.
  • Pinned items are strictly locked to the top of the grid and list. They will never get pushed down by newly added or frequently clicked unpinned items.
  • Clicking the pin button again unpins the card and returns it to normal recency-based sorting.
Click the ✕ button located at the top-right corner of any card (it highlights in Windows close-red on hover). The shortcut is instantly removed from your view and saved.

Note: Removing a shortcut only deletes the bookmark in iROP Quick Access; your actual files, folders, and drives are never touched or modified.
Right-clicking on any card reveals a convenient context menu:
  • Open / Launch: Opens the folder or executes the file.
  • Pin to Top / Unpin: Locks or unlocks the shortcut to the top.
  • Rename: Assigns a friendly custom display name to the card without altering the actual filesystem directory name.
  • Copy Path: Copies the full filesystem path to your Windows clipboard.
  • Remove Shortcut: Deletes the shortcut card.
You can toggle view modes anytime via the view selector:
  • Grid View (205x105): Multi-column rectangular cards featuring proportional icons, bold title, single-line middle-elided path, and usage statistics. Best for large desktop monitors.
  • List View (Auto 100% Wide): Horizontal full-width rows with a prominent 40px icon on the left, followed by title, full path, and usage statistics stacked neatly. Ideal for compact or dense directory overviews.

১. পরিচিতি ও মূল উদ্দেশ্য
iROP Quick Access হলো একটি হালকা ও দ্রুতগতির উইন্ডোজ ডেস্কটপ শর্টকাট হাব। প্রতিদিন কাজের সময় বারবার "This PC" ওপেন করে ড্রাইভের গভীরে থাকা সাব-ফোল্ডারে গিয়ে সময় নষ্ট হওয়া রোধ করতে এটি তৈরি করা হয়েছে।
যেকোনো ফোল্ডার, ড্রাইভ, সফটওয়্যার (.exe) কিংবা ফাইল টেনে এনে অ্যাপের উইন্ডোতে ড্রপ করলেই তা তৎক্ষণাৎ ভিজ্যুয়াল কার্ডে পরিণত হয়।
আপনার ব্যবহারের অনুপাত ও রিকেন্সি (Most Recent) অনুযায়ী কার্ডগুলো স্বয়ংক্রিয়ভাবে সাজানো থাকে, ফলে প্রয়োজনীয় ফাইলটি সবসময় সবার উপরে থাকে।
এটি একটি সার্বজনীন মাল্টি কুইক অ্যাক্সেস সিস্টেম। এতে যুক্ত করা যায়:
  • লোকাল ফোল্ডার ও প্রজেক্ট ডিরেক্টরি: যেমন—C:\Projects, D:\ClientWork ইত্যাদি।
  • হার্ড ড্রাইভ ও নেটওয়ার্ক ড্রাইভ: যেমন—C:\, D:\, T:\Multimedia ইত্যাদি।
  • সফটওয়্যার ও অ্যাপ্লিকেশান: যেমন—.exe ফাইল এবং ডেস্কটপ শর্টকাট (.lnk)।
  • সাধারণ ফাইল ও ডকুমেন্ট: যেমন—.psd, .ai, .docx, .xlsx, .pdf ইত্যাদি।
আপনি ৩টি সহজ উপায়ে শর্টকাট যোগ করতে পারেন:
  1. ড্র্যাগ অ্যান্ড ড্রপ (সবচেয়ে দ্রুত): ডেস্কটপ বা ফাইল এক্সপ্লোরার থেকে যেকোনো ফোল্ডার বা ফাইল টেনে এনে উইন্ডোর ওপর ছেড়ে দিন।
  2. টপ মেনু বাটন: ওপরের ➕ Add Folder/App বাটনে ক্লিক করে 📁 Add Folder or Drive... অথবা ⚡ Add Application or File... নির্বাচন করুন।
  3. স্বয়ংক্রিয় ইমপোর্ট: 📥 Import Quick Access বা 📂 Import Open Windows বাটনে এক ক্লিকেই একসাথে একাধিক শর্টকাট নিয়ে আসুন।
স্মার্ট উইন্ডো ফোকাস: যদি কোনো ফোল্ডার ইতিমধ্যে টাস্কবারে ওপেন বা মিনিমাইজ করা থাকে, তবে iROP Quick Access নতুন করে কোনো ডুপ্লিকেট উইন্ডো খুলবে না। বরং বিদ্যমান মিনিমাইজড উইন্ডোটিকে সাথে সাথে স্ক্রিনের সামনে (Foreground Focus) নিয়ে আসবে। আর যদি খোলা না থাকে, তবে নতুন এক্সপ্লোরার উইন্ডোতে চালু করবে।
২. কন্ট্রোলবার ও সেটিংস গাইড
📥 Import Quick Access বাটনে ক্লিক করলে এটি উইন্ডোজের আসল কুইক এক্সেস শেল নেমস্পেস চেক করে। আপনার পিসির বিভিন্ন ড্রাইভে (C:, D:, E:, T:) পিন করা সমস্ত ফোল্ডার স্বয়ংক্রিয়ভাবে ডিটেক্ট করে এবং সেগুলোকে সরাসরি টপে পিন করে ইমপোর্ট করে।
কাজের সময় আপনার টাস্কবারে বর্তমানে যেসব ফোল্ডার খোলা আছে, 📂 Import Open Windows বাটনে এক ক্লিক করলেই সবগুলো খোলা উইন্ডোর পাথ একসাথে শর্টকাট হিসেবে যুক্ত হয়ে যাবে।
টপবারের ক্লিক ড্রপডাউন থেকে আপনার পছন্দমতো মোড নির্বাচন করতে পারেন:
  • Single Click to Open: মাউসের এক ক্লিকেই ফোল্ডার বা সফটওয়্যার ওপেন হবে (দ্রুত কাজের জন্য আদর্শ)।
  • Double Click to Open: উইন্ডোজের স্ট্যান্ডার্ড নিয়মে ডাবল ক্লিকে ওপেন হবে, যাতে ভুলবশত ক্লিক হওয়া এড়ানো যায়।
টপবারের Size: স্লাইডার টেনে কার্ডের প্রস্থ ১৫০px থেকে ৩৫৫px পর্যন্ত ছোট-বড় করা যায়।
  • প্রোপোরশনাল আইকন স্কেলিং: কার্ড বড় বা ছোট করার সাথে সাথে ভেতরের আইকনটিও অনুপাত অনুযায়ী ২৪px থেকে ৪৮px পর্যন্ত বড়-ছোট হয়।
  • ↺ Default বাটন: এই বাটনে চাপলে কার্ডের সাইজ মুহূর্তেই স্ট্যান্ডার্ড ডিফল্ট ২০৫x১০৫ সাইজে রিসেট হয়ে যায়।
থিম বাটন এবং অ্যাবাউট বাটনের মাঝে থাকা 💾 Save ড্রপডাউন থেকে:
  • Export Shortcuts...: আপনার সমস্ত শর্টকাট ও ক্লিক হিস্ট্রি একটি ফাইলে ব্যাকআপ আকারে সেভ করে রাখা যায়।
  • Import Shortcuts...: যেকোনো পূর্ববর্তী ব্যাকআপ ফাইল থেকে শর্টকাটগুলো পুনরায় ফিরিয়ে আনা যায়।
  • Clear All Shortcuts...: কনফার্মেশন নিয়ে এক ক্লিকেই সমস্ত শর্টকাট ক্লিয়ার করা যায়।
৩. কার্ডের খুঁটিনাটি ও কনটেক্সট মেনু
প্রতিটি কার্ডের ওপরের ডান কোণায় একটি করে 📌 পিন বাটন রয়েছে।
  • লক টু টপ: পিন বাটনে ক্লিক করলে কার্ডটির বর্ডার ও পিন হাইলাইট হয়ে যায় এবং কার্ডটি গ্রিড বা লিস্টের সবার উপরে স্থায়ীভাবে লক হয়ে থাকে।
  • অন্যান্য ফোল্ডার যতবারই ওপেন করা হোক না কেন, পিন করা ফোল্ডার কখনোই নিচে নামবে না।
  • পুনরায় পিন বাটনে ক্লিক করলে আনপিন হয়ে স্বাভাবিক সর্টিং অর্ডারে ফিরে যাবে।
যেকোনো কার্ডের ওপরের ডান কোণায় থাকা ✕ বাটনে ক্লিক করলেই শর্টকাটটি তালিকা থেকে মুছে যাবে।

মনে রাখবেন: এটি শুধুমাত্র শর্টকাট বুকমার্কটি ডিলিট করে, আপনার আসল ফোল্ডার বা ফাইলের কোনো ক্ষতি হয় না।
যেকোনো কার্ডের ওপর মাউসের রাইট-ক্লিক করলে বিশেষ মেনু পাওয়া যায়:
  • Open / Launch: সরাসরি ফোল্ডার বা ফাইল ওপেন করে।
  • Pin to Top / Unpin: সবার ওপরে লক বা আনলক করে।
  • Rename: ড্রাইভের মূল ফোল্ডার নেম অপরিবর্তিত রেখে কার্ডে নিজের ইচ্ছামতো সুন্দর নাম দেওয়া যায়।
  • Copy Path: সম্পূর্ণ পাথ এক ক্লিকে ক্লিপবোর্ডে কপি করে।
  • Remove Shortcut: শর্টকাটটি রিমুভ করে।
টপ মেনু থেকে সহজেই ভিউ পরিবর্তন করা যায়:
  • Grid View (205x105): চারকোনা মাল্টি-কলাম কার্ড, যাতে আইকন, টাইটেল, হালকা গ্রে পাথ এবং ব্যবহারের হিসাব সুন্দরভাবে সাজানো থাকে। বড় স্ক্রিনের জন্য উপযুক্ত।
  • List View (Auto 100% Wide): ফুল-উইডথ এক সারির তালিকা, যাতে বামে বড় ৪০px আইকন এবং পাশে টাইটেল, পাথ ও ব্যবহারের সময় পরপর সাজানো থাকে।
৪. কুইক ফিচার ও অ্যাকশন টেবিল
ফিচার / অ্যাকশন কন্ট্রোল বা বাটন ডিফল্ট মান বিবরণ
ফোল্ডার বা ড্রাইভ যুক্ত করা ড্র্যাগ অ্যান্ড ড্রপ বা ➕ মেনু — ফোল্ডার ড্রপ করলেই সরাসরি শর্টকাট কার্ড তৈরি হবে।
সফটওয়্যার বা ফাইল যুক্ত করা ড্র্যাগ অ্যান্ড ড্রপ বা ➕ মেনু — .exe, .lnk বা প্রজেক্ট ফাইল ড্রপ করে অ্যাড করা যায়।
কুইক এক্সেস ইমপোর্ট 📥 Import Quick Access — উইন্ডোজ এক্সপ্লোরারে পিন করা সব ড্রাইভের ফোল্ডার ইমপোর্ট করে।
ওপেন উইন্ডোজ ইমপোর্ট 📂 Import Open Windows — টাস্কবারে খোলা থাকা এক্সপ্লোরার উইন্ডোগুলো যোগ করে।
পিন / লক টু টপ 📌 বাটন (কার্ডের ওপরে) আনপিন্ড শর্টকাটটি সবার ওপরে স্থায়ীভাবে আটকে রাখে।
কার্ডের সাইজ স্কেলিং Size স্লাইডার (১৫০–৩৫৫px) ২০৫W x ১০৫H কার্ড বড় করার সাথে সাথে আইকনও অনুপাতে বড় হবে।
ডিফল্ট সাইজ রিসেট ↺ Default বাটন — মুহূর্তেই সাইজকে স্ট্যান্ডার্ড ২০৫x১০৫ মাপে ফিরিয়ে আনে।
ক্লিক অপশন Click Mode ড্রপডাউন Double Click সিঙ্গেল বা ডাবল ক্লিকে ওপেন করার অপশন।
